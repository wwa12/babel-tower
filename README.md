# 巴别塔 · Babel Tower

简体中文 | [English](README.en.md)

用快捷键呼出的 Mac 翻译浮窗：复制一段文字或截一张图，按 ⌥T 出译文；再按回车，译文进剪贴板，浮窗收起。

只在**简体中文、繁体中文、日语、英语**四种语言之间互译，翻译交给你自己配置的多模态大模型（任何 OpenAI 兼容接口都行）。不需要任何系统权限，没有账号，也没有项目自己的服务器——翻译内容只发给你选的模型服务。

> **项目状态：早期。** 功能都已实现，但还没有用真实模型系统地测过首字延迟和翻译质量，预设里的默认模型名也还是占位值。欢迎试用和反馈，暂不建议当作稳定工具依赖。

## 能做什么

- **三次按键走完主路径**：复制（⌘C）→ 呼出（⌥T）→ 带走译文（↩）。60 秒内复制过的内容，呼出时会自动带入并开始翻译。
- **文字、图片、图文混合共用一个输入区**：粘贴或拖入图片（最多 4 张），界面截图、聊天记录、表格、海报都能按阅读顺序翻译；文字和图片一起发时互为语境，术语保持一致。
- **自动判断翻译方向**：主语言的内容译成常用外语，其他语言译成主语言；⌘1–4 强制译成简 / 繁 / 日 / 英，⌘0 回到自动。
- **流式输出、只给译文**，不解释、不寒暄；⌘C 没有选区时复制全文，有选区时只复制选中部分。
- **图钉固定**：钉住后点击外部不收起，适合连续查多段内容。
- **可自定义系统提示词**。

## 不做什么

巴别塔刻意做得很窄。目前明确不做：划词取词、内置截图、把译文覆盖到原图上、整页或文档翻译、多引擎对比、词典与发音、四种以外的语言、账号与云同步。

## 隐私与权限

- 不申请辅助功能、屏幕录制、输入监控等任何系统权限，全新安装不会出现权限弹窗。
- API Key 只保存在本机系统钥匙串，不写入任何文件，也不随设置同步。
- 待翻译内容只发送给你配置的模型服务，不收集任何使用数据。

## 系统要求

- macOS 14 或更新，Apple 芯片与 Intel 都支持。
- 一个支持图片输入的多模态模型服务 API Key：OpenAI、阿里云百炼、火山方舟，或任意 OpenAI 兼容接口。
- 从源码构建需要 Xcode（目前在 Xcode 26 上验证过）。

## 从源码构建

```bash
git clone https://github.com/wwa12/babel-mac.git
```

```bash
cd babel-mac/app && open 巴别塔.xcodeproj
```

在 Xcode 里选「巴别塔」scheme，按 ⌘R 运行。也可以在 `app/` 目录下用命令行构建：

```bash
xcodebuild build -project 巴别塔.xcodeproj -scheme 巴别塔 -configuration Release -destination 'platform=macOS'
```

巴别塔是菜单栏应用，没有 Dock 图标。首次启动会出现引导：选择模型服务、填 API Key、点「测试连接」。预设里的默认模型名是占位值，请改成你账号里实际可用的模型。

**关于钥匙串授权弹窗**：工程默认用临时签名。每次重新构建后，App 第一次读取 API Key 时，macOS 会询问是否允许访问钥匙串，点「始终允许」即可。想彻底避免，可以在 Xcode 里改用你自己 Apple ID 的开发证书签名。

## 快捷键

| 按键 | 作用 |
|---|---|
| ⌥T | 呼出 / 收起浮窗（全局生效，可在设置里修改） |
| ↩ | 翻译；译文完成后变为"复制并收起" |
| ⇧↩ | 换行 |
| ⌘V | 粘贴文字或图片 |
| ⌘1 / ⌘2 / ⌘3 / ⌘4 | 目标语言设为简中 / 繁中 / 日语 / 英语 |
| ⌘0 | 目标语言回到自动 |
| ⌘C | 复制译文（有选区时只复制选区） |
| ⌘R | 重新翻译 |
| ⌘N | 清空，开始新一轮 |
| ⌘, | 打开设置 |
| Esc | 收起浮窗 |

## 技术概览

Swift + SwiftUI，浮窗是 AppKit 的非激活 `NSPanel`；网络用 `URLSession` 自行解析 SSE 流式响应，只对接 OpenAI 兼容接口。唯一的第三方依赖是 [KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts)（全局快捷键）。

```
app/
  BabelTower/      App 源码：Panel（浮窗）、Translation（引擎与流式解析）、Clipboard、Imaging、Settings、Onboarding
  Tests/           单元测试与界面级测试
  巴别塔.xcodeproj
```
